3. Database
-ปรับโครงสร้างการเก็บข้อมูล content.json ให้เป็นดังนี้             
{"content": [
  {
    "title": "",
    "description": "",
    "img": [{ imgSrc: "" }]
  }
]}  

โดยต่อ 1 บทเรียนภายใน course ต้องมี content มากกว่า 1 ใน array และเก็บ img เป็น base64 ใน content.json ไม่มีการส่งไฟล์ไปเก็บที่ backend storage ช่วยลดพื้นที่ไฟล์ที่ต้องเก็บใน backend   ***Success***

announce_state:
0 = คะแนนอยู่ระหว่างการประมวลผล
1 = คะแนนรวมของแบบทดสอบก่อนเรียนอย่างเดียว
2 = คะแนนรวมของแบบทดสอบก่อนและหลังเรียน
3 = คะแนนรวมของแบบทดสอบก่อนและหลังเรียน + รายละเอียดข้อสอบที่ได้และไม่ได้คำแนน + อัตตราการได้ความรู้เพิ่มเติมคิดจากคะแนนแบบทดสอบหลังเรียน - คะแนนแบบทดสอบก่อนเรียน และนำไปคิดเป็น %
